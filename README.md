# ReportTools

这是一个基于 C# 和 Excel VSTO 开发的报表辅助工具，主要用于在 Excel 工作表中快速处理激光报表相关操作。

## 项目简介

该项目是一个 Excel 插件（Add-in），适用于在 Excel 中进行激光生产报表和物料处理工作，帮助用户更高效地完成数据录入、计算、跳转和打印等任务。

## 主要功能

- 跳转到订单数据
- 材料和打包计算
- 套料/排版辅助
- 标签打印
- 生产日报数量填充
- 生成材料计算表

## 技术特点

- 使用 C# 开发
- 面向 Microsoft Excel 的 VSTO 扩展
- 集成 Ribbon 菜单，方便在 Excel 中直接调用功能

## 说明

这是一个偏实用型的办公自动化工具项目，重点在于提升 Excel 报表工作流的效率，而不是通用 Web 应用程序。
